## 视觉缺陷修复（用户反馈：输入框聚焦变白底、图片框有白光）

用户反馈两点：①点输入框时内容框变成白底很难受；②照片/视频方框右上角有白光影响观看。

用无头 Chrome 截图定位（`--headless=new --force-prefers-reduced-motion`，后者用来跳过 `.reveal` 入场动画，否则截图全黑），发现真实原因比反馈更严重：
- **深色模式下所有素材框变成亮白卡片**：MediaFrame.vue 里 scoped 写死了 `background:linear-gradient(150deg,#e7e7ec,#d3d4dc)`，作用域选择器带 data 属性，优先级压过了深色主题的 `.ph` 底色。
- 白光来自 `.ph::before` 那层 `radial-gradient(...rgba(255,255,255,.9)...)` 白色高光，深色模式下尤其刺眼。
- 输入框聚焦变白底：`.field input:focus{background:#fff}` 和 admin.css 的 `.f input:focus{background:#fff}` 都没区分主题。

修法（三处）：
1. 引入主题 token `--ph-bg / --ph-ink / --field-bg / --field-bg-focus`，深浅两套都在 `:root` 里定义；`.ph` 与输入框一律用 token。
2. **删掉 `.ph::before` 白色高光层**（媒体框上不再叠任何发光层），MediaFrame.vue 里写死的浅色渐变也删掉。
3. 聚焦态只做「轻微提亮 + 蓝描边 + 4px 外发光」，不刷白；admin.css 深色块里补一条同优先级的 `:focus` 规则，否则暗色底会盖掉聚焦样式（`.f input:not([type=checkbox])` 与 `.f input:focus` 优先级同为 0,2,1，靠源顺序决胜）。
- 另把 `--spec`（镜面高光强度）在深色模式下从 .55 降到 .22。
- 无头截图技巧：`--force-prefers-reduced-motion` 必加，否则 `.reveal{opacity:0}` 让整页内容不可见；本机 Chrome 在 `C:\Program Files\Google\Chrome\Application\chrome.exe`。
